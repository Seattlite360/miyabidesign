## Quick start (Illustrator)

1. Install Manrope, Poppins, Newsreader from Google Fonts (links in `sylva-palette-type-spec.md`).
2. Load `assets/swatches/Sylva-Palette.ase` into the Swatches panel, or run
   `illustrator/sylva-setup.jsx` on a new document.
3. Open the templates in `illustrator/` — wordmark lockup (light + dark), palette sheet, type
   specimen — all live text and exact hex fills, ready to build from.

Nothing here is final: the wordmark pairing is a recommendation and "Sylva Residences" isn't
IP Australia–cleared yet. Details in `00-status-and-handoff.md`.
