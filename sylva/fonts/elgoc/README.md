# Elgoc (tagline and emphasis font, type version v2)

Elgoc by Neuebel with Mark and Firman Suci Ananda is free for **personal use only**.
Buy the commercial licence before this page goes to a client or goes live.

The page finds Elgoc in two ways, in this order:

1. **Installed on the computer viewing the page.** Your Mac already has it, so it works there as is.
2. **A file in this folder**, for every other device. Add one of these (same name, any one format):
   - `Elgoc.woff2` (best)
   - `Elgoc.otf`
   - `Elgoc.ttf`

   Use the regular upright style. To convert an .otf to .woff2, any webfont converter works.

Until a file is here, other devices fall back to Ambroise, or Bodoni Moda if the Adobe kit is blocked.
