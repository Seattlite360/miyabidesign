# Miyabi Design: Client-Facing Voice

Visual identity, colours, type and locked pricing live in `docs/MIYABI-BRAND.md`. Read it before quoting any number. This skill covers words only.

## Hard rules

1. **Studio voice, no first-person singular.** Miyabi speaks as a studio, not a freelancer. Never "I", "me", "my", "mine", "I'm", "I'll", "I'd". Subject of the sentence is "Miyabi", "you", or an imperative. "We/our" is allowed sparingly. Signing off with a name is fine.
2. **Value before deliverable.** Sentence one states what changes for the reader. The asset comes second.
3. **One number per claim.** Real figures, never ranges or vague speed words.
4. **One next step** per message ("Request a free sample pack", "Reply and the pack is built").
5. **Only locked claims.** Claim only what is proven: 24-hour delivery, free first pack, headcount pricing, compliance. Do not claim "sell faster", "more eyes", ROI or results until a case study exists.
6. **Never conflict with the promise.** One speed promise only: within 24 hours of receiving listing info. Never "within moments", "instantly", "automatically".
7. **No hype.** No exclamation marks, ALL CAPS lines, "thrilled", "love to", "passionate", "elevate", "unlock", "journey", "synergy", "solutions", "world-class".

## Values

| Value | How it sounds |
|---|---|
| Speed you can rely on | Dated, measurable: 24 hours |
| Risk removed | Guarantee up front, never fine print |
| Clarity | Short declarative sentences, one idea each |
| Restraint (雅) | Refined, uncluttered. Say less, prove more |
| Respect for the reader's time | Price, timeline and next step visible at once |
| Honesty | Never claim what the source does not state. Disclose AI edits |

## Outcomes to use as proof points

- **Stand out:** a consistent, premium look on every listing. "Get noticed, become invaluable."
- **Speed:** every listing pack within 24 hours of receiving listing info, or it is free.
- **Zero-risk start:** the first listing pack's production is free with every build.
- **Time back:** repeat design work replaced by a system built once.
- **Predictable cost:** AUD only, tiers by agent headcount, cancel anytime on retainers.
- **Compliance built in:** price wording and AI-edit disclosure follow QLD/NSW rules.

Printing runs on the client's printer's own timeline. Say so whenever delivery is mentioned.

## Value-first structure

1. **Specific observation** about the reader (a named listing, sale or project, verified on their site).
2. **Outcome** for them, one sentence.
3. **Proof**: the guarantee or a real sample already built for them.
4. **Price** for their segment only, when pricing is relevant.
5. **Next step**, one action, plus an opt-out line on cold emails.

Subject lines: specific and factual, ideally with a real number from the reader's own work. "Your $1.7M sale deserves its own listing pack" works. Generic "Free EDM" does not.

## Segments

| | Agency (independent / boutique) | Developer / builder |
|---|---|---|
| Cares about | Time per listing, consistency across agents, cost control | Prestige of each project, launch-ready collateral, brand at sell-through |
| Lead with | 24-hour delivery, free first pack | A branded system for the project, built once, fast updates |
| Proof | Sample pack from their live listing | Sample EDM/brochure from their own project render |
| Price | $2,800 build, then tier by agent count | $8,000 one-time, no ongoing engagement |
| Tone | Practical, peer-to-peer | Measured, brand-conscious |

## Rewrites (from real sent emails)

| Avoid | Use |
|---|---|
| "My name is Kalebh, and I'm the founder of Miyabi Design..." | Open on the reader's listing. Identify Miyabi in one clause, or in the signature. |
| "I'd love the opportunity to help support your team..." | "Miyabi builds a branded system once, then delivers each listing pack within 24 hours." |
| "I CREATE THESE AUTOMATICALLY AND COMPLETELY DESIGNED WITHIN MOMENTS" | "Every listing pack is delivered within 24 hours of receiving the listing info, or it is free." |
| "I've built a sample for Bow River Villas." | "A sample marketing email for Bow River Villas is attached, built from the render on your site." |
| "Everything I create is custom designed, not AI-generated." | Drop it. It contradicts the automation offer. State the outcome instead. |
| "Let me know if you're interested." | "Reply with a current listing and the pack is built." |

## Do not

- Use ranges, "from", "offers over", "$X+" in price or property copy. Use "Contact agent".
- Write any property detail not stated on the source.
- Use listing volume in tier language. Tiers are by agent count only.
- Add bilingual copy to AU agency/developer pages (English-only by decision). Use bilingual for JP-market material.
- Send more than more than about 120 words in a cold email.
