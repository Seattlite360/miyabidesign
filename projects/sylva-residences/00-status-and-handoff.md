## 1. The naming decision

- **"Sylvan Residences" is dead.** Pradella already press-named their competing tower "Sylvan
  Residences" at 70 Sylvan Road — a few hundred metres up the same street. Real collision:
  same street, same market, already public. Not usable.
- **"Sylva Residences" is the working name**, chosen as the safe substitute. Same sound,
  same treatment originally asked for. Cleared at web-search level — no competing project on
  the street or in the immediate market using it.
- **"Sylvia" was raised as a personal preference but never actually cleared.** If you want it
  back in consideration, it needs the same web-search pass Sylva already went through before
  it's a real option — don't assume it's clean.
- **Nothing here is IP Australia–cleared.** That's a real trademark search, still outstanding,
  and the last gate before anything goes to print or in front of John.

## 2. The brand system, decided so far

- **Wordmark:** Manrope ExtraBold (SYLVA) + Poppins Light, tracked caps (RESIDENCES) —
  recommended, not locked. Poppins Light ties back to Miyabi's own body face. Two solid
  alternates and the full five-pairing comparison are in `sylva-logomark-brief.md`.
- **Palette:** nine tokens (Stone, Stone 2, Ink, Ink Soft, Copper, Sage, Umber, Rule, Card),
  light and dark values. Full hex table in `sylva-palette-type-spec.md`, and as literal pixel
  colour in `sylva-color-swatches.png` in this folder — eyedropper straight from that file in
  Illustrator/Figma rather than retyping hex codes by hand.
- **Typography:** Manrope / Poppins for the wordmark, Poppins Light for supporting copy,
  Newsreader italic as an optional editorial accent (used across both the Understory and Sylva
  boards).
- **Art direction:** full-bleed, photography-led, editorial — not real-estate stock. Warm
  dusk/interior tones. The two reference renders are in this folder
  (`sylva-render-01.png`, `sylva-render-02.png`) — both AI-generated, so any use of them in
  front of John needs the same AI-disclosure label as everywhere else in this pitch.
